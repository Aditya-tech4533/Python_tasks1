# 🎮 Hangman Game in Python

## 📌 Description
Hangman is a simple **text-based word guessing game** developed using Python. The computer randomly selects a word from a predefined list, and the player has to guess the word one letter at a time.

The player gets a maximum of **6 wrong guesses**. The game ends when the player successfully guesses the complete word or uses all 6 wrong attempts.

## 🎯 Objective
To create a simple interactive game and understand basic Python programming concepts such as loops, conditions, lists, strings, and the random module.

## 🛠️ Topics / Concepts Used
- Python Programming
- Random Module
- Lists
- Strings
- Variables
- `input()` and `print()`
- `if-elif-else`
- `for` loop
- `while` loop
- `break` statement
- Membership operator (`in`)
- Basic game logic

## 🎮 How to Play
1. Run the Python program.
2. A random word will be selected.
3. Guess one letter at a time.
4. Correct letters will be displayed.
5. Incorrect guesses increase the wrong-guess counter.
6. You have **6 chances** for wrong guesses.
7. Guess the complete word to win.

## 📋 Predefined Words
The game randomly selects one word from:

- Python
- Computer
- Program
- Coding
- Student

## ▶️ How to Run

Make sure Python is installed on your computer.

```bash
python hangman.py
```
